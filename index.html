モンスターデータと配合レシピを含むJSONファイルを読み込めます。データはこのブラウザに保存されます。既存データは置き換えられます。

JSONの仕様・記述例
{
 "monsters":[
  {"id":"slime","name":"スライム","kana":"すらいむ","rank":"F","family":"スライム系","order":1}
 ],
 "recipes":[
  {"result":"slime","type":"special","parents":["slime","slime"],"note":"例示用"}
 ]
}

type: special（特殊配合）、rank（位階配合）、four（4体配合）、other（その他）。parents はモンスターID配列。位階配合は families（親系統の配列）、minOrder / maxOrder（結果の位階範囲）も指定可能。個別の位階判定はゲーム固有の計算規則を検証してから実装します。

非公式ファン制作ツール。ゲームの権利は各権利者に帰属します。
